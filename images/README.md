## hydrafacial-machine.webp

The HydraFacial machine product shot, used by the homepage feature section and
the /hydrafacial page as `/images/hydrafacial-machine.webp`.

- 1000 x 1513, WebP with a **transparent background** (alpha channel)
- Derived from the original 2500 x 3332 source: transparent margins trimmed,
  resized for web (927 KB -> 59 KB)

Because the background is transparent, the CSS uses `object-fit: contain` over a
light "stage" gradient (`.hydra-media-frame`) rather than `cover` — this keeps the
whole unit visible and keeps its dark body readable on the dark hero.

If you replace this file, keep the transparency and a portrait orientation, or
adjust `.hydra-media-frame` in styles.css to suit the new dimensions.
